# CampusBot – AI College Assistant

## 1. Project Overview
CampusBot is an AI-powered student information assistant developed for Karnavati University, Gandhinagar, Gujarat.

It helps students access university-related information through a conversational chatbot interface.

## 2. Objectives
- Provide quick access to university information.
- Assist students with academic and admission-related queries.
- Improve access to campus information.
- Use AI to generate relevant responses to student questions.

## 3. Key Features
- AI-powered chatbot.
- Course and programme information.
- Admission guidance.
- Examination and attendance information.
- Campus facilities information.
- University contact information.
- Interactive chat interface.

## 4. Technologies and AI Tools
- Google AI Studio – AI-assisted application development.
- Gemini – AI-powered chatbot responses.
- GitHub – Source code management and project hosting.

## 5. Development Process
1. Identified the problem of students having difficulty accessing university information.
2. Selected CampusBot as the proposed AI-based solution.
3. Used Google AI Studio to generate the application.
4. Integrated Gemini-powered conversational responses.
5. Tested the chatbot using different student queries.
6. Identified response-quality issues and improved the AI instructions.
7. Uploaded the generated project files to GitHub.

## 6. Testing
The chatbot was tested using questions related to:
- Courses and programmes.
- Admission procedures.
- Campus facilities.
- Examination information.
- Scholarships.
- Unavailable or unsupported courses.

## 7. Expected Outcome
A user-friendly AI assistant that helps students access university-related information quickly and conveniently.
## 8. Deployment

The CampusBot application was successfully deployed using Vercel.

- **Deployment Platform:** Vercel
- **Source Code Repository:** GitHub
- **Live Application:** https://campusbot-tawny.vercel.app/

The deployed application provides students with access to the CampusBot interface through a web browser.

## 10. Project Status

The AI-based CampusBot application has been developed, tested and deployed successfully.
## 8. Conclusion
CampusBot demonstrates how generative AI tools can be used to develop an AI-based application that addresses a practical problem in the education sector.
